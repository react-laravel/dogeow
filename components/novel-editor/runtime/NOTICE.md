# Editor runtime attribution

This runtime adapts the editor UI concepts, upload placeholders and legacy `math`,
`twitter` and `ai-highlight` schema compatibility from Novel 1.x by Steven Tey and
contributors, licensed under Apache-2.0.

Source: https://github.com/steven-tey/novel

The DogeOW implementation has been changed to use official Tiptap 3 packages,
Floating UI menus, native image resizing and the official Markdown manager.
It does not distribute the Novel npm package or Tiptap 2. The Apache-2.0 license
is included in `LICENSE-NOVEL` alongside this notice.
